# CampusCrib
1. Project Title
Campus Crib: A Cloud-Based Student Hostel and Room Finder Platform

2. Group Members
Benjamin Asare Marfo (Working solo)

3. Problem Statement
Finding a good room or hostel around campus in Accra is very hard for students. Students waste a lot of time walking around searching, or they fall victim to fake agents who collect money and lie about room prices. There is no simple, trusted place online where students can see real rooms, check prices, and contact house owners directly.

4. Project Objectives
Build a simple website where house owners and agents can register and post available rooms.

Allow students to search for rooms based on location and price.

Enable secure user login and registration for both students and landlords.

Store all room data safely in a database and keep room pictures in cloud storage.

Deploy the whole system live on AWS so anyone can access it on the internet.  


5. Proposed Technologies and AWS Services
To meet all school requirements, the project will use these tools:  

Frontend: HTML, CSS, and JavaScript (or React) for a clean user interface.

Backend: Python (Flask or Node.js) to run the server.

IAM (Identity and Access Management): To control user access securely.  

Amazon EC2: To host the web application on a virtual server.  

Security Groups: To protect the server like a firewall.  

Amazon RDS: A managed database to store user accounts and room details.  

Amazon S3: To store room pictures uploaded by landlords.  

CloudWatch: To monitor server performance and logs.
